# Todo List Application

A simple and user-friendly Todo List application designed to help users manage their daily tasks efficiently.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- View pending and completed tasks
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the Todo List application.
2. Enter a task.
3. Click the Add button.
4. Mark tasks as completed when finished.
5. Edit or delete tasks when required.

## Purpose

The main purpose of this application is to help users organize and manage their daily tasks easily.
